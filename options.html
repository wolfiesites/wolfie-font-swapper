Reguły domen

Automatycznie wczytaj preset na pasujących domenach (glob, np. *.wolfiesites.com).

Jak fonty działają na stronie — w skrócie

    body, * {
  font-family: "Arial", sans-serif;
}

    Self-hosting — własny plik fonta (+ licencja)

    @font-face {
  font-family: "My Font";
  src: url("/fonts/my-font.woff2") format("woff2"),
       url("/fonts/my-font.woff")  format("woff"),
       url("/fonts/my-font.ttf")   format("truetype");
  font-weight: 400;
  font-display: swap;
}
body, * {
  font-family: "My Font", sans-serif;
}
